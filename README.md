# TT Vape

Vape-inspired utility client for **Minecraft NeoForge 26.2**.

Separate project from [TT-Client](https://github.com/ben757119-cmyk/TT-Client).

## Look
- Purple accent (`#8B5CF6`)
- Dark panels, clean arraylist
- `vape` watermark
- Right Shift ClickGUI

## Build
```bash
./gradlew build
```
JAR: `build/libs/ttvape-1.0.0.jar`

## Controls
- **Right Shift** — ClickGUI
- Client commands start with `.`

Client-side only. Use responsibly.
